# Audio Interface Diag Wiki

Audio Interface Diag (AID) is a diagnostic tool for audio interfaces, a sister of DeckChek and MIDI Test.
It runs in three modes on one shared engine: Live (passive monitoring), DAW (non-disruptive production
checks) and Engineer/Technician (armed active tests such as loopback latency).

Shipped as a CLAP plugin, VST3 plugin and standalone app for Windows and Linux (release downloads on GitHub).
Version 0.0.1 beta.
